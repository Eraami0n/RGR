# Менеджер спортивного клубу

Повнофункціональна система управління спортивним клубом на C++ з Windows Forms.

## 🎯 Можливості

- **Управління спортсменами**: додавання, редагування, видалення
- **Розклад тренувань**: планування та управління тренуваннями
- **Облік платежів**: контроль оплат членів клубу
- **Статистика**: аналіз даних та фінансові звіти

## 🏗️ Архітектура

### Головні компоненти:

1. **SportsClubManager** - основний клас для управління даними
2. **MainForm** - графічний інтерфейс (Windows Forms)
3. **Структури даних**: Athlete, Training, Payment

## 🚀 Запуск

### Вимоги:
- Visual Studio 2019 або новіше
- Windows SDK
- C++ 17 або новіше

### Компіляція через Visual Studio:
```
1. Відкрийте SportsClubManager.vcxproj
2. Build → Build Solution
3. F5 або Debug → Start Debugging
```

### Компіляція через командний рядок:
```bash
cl /EHsc main.cpp SportsClubManager.cpp MainForm.cpp /link user32.lib comctl32.lib
main.exe
```

## 🎨 Інтерфейс

### Вкладки:
1. **Спортсмени** - список учасників, додавання/видалення
2. **Тренування** - розклад та управління тренуваннями
3. **Платежі** - облік платежів
4. **Статистика** - загальна інформація про клуб

## 📊 Функціональність

### Управління спортсменами
- Додавання нових учасників
- Редагування інформації
- Видалення з системи
- Контроль категорій та платежів

### Управління тренуваннями
- Створення розкладу
- Призначення тренерів
- Визначення місця проведення
- Облік учасників

### Облік платежів
- Реєстрація платежів
- Відслідження статусу оплати
- Контроль несплачених платежів
- Статистика доходу

### Статистика
- Загальна кількість спортсменів
- Загальний дохід
- Кількість непроплачених платежів
- Аналіз за місяцями
